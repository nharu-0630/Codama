# 投稿の取得と表示

## 概要
地図上に会話を吹き出しとして表示するKodamaアプリの中核機能を実装した。

## 実装内容

### 1. データモデルの作成

#### Post モデル (`lib/features/post/models/post.dart`)
```dart
enum PostKind { user, land }

class Post {
  final String id;
  final double lat;
  final double lng;
  final PostKind kind;
  final String text;
  final DateTime createdAt;
  final String? userId;
}
```
- 投稿の種類を `user`（ユーザー投稿）と `land`（土地の記憶）で分類
- 地理座標（lat/lng）を保持して位置情報と紐付け

#### BubblePosition モデル (`lib/features/post/models/bubble_position.dart`)
```dart
enum BubbleDisplayKind { me, friend, land, all }

class BubblePosition {
  final Post post;
  final LatLng position;
  final bool isVisible;
  final BubbleDisplayKind displayKind;
}
```
- 投稿の地図上での表示位置を管理
- 表示種別（自分/友達/土地の記憶）を定義

### 2. サービスレイヤーの実装

#### SimplePostService (`lib/features/post/services/simple_post_service.dart`)
```dart
class SimplePostService {
  final List<Post> _posts = [];
  
  void addPost({...});
  List<Post> getAllPosts();
  void addDemoPosts();
}
```
- 投稿データの基本的なCRUD操作を提供
- デモ用の投稿を横浜駅周辺に配置する機能

#### BubbleManager (`lib/features/post/services/bubble_manager.dart`)
```dart
class BubbleManager {
  List<BubblePosition> layoutBubbles(
    List<Post> posts,
    ViewBounds viewBounds,
    String? currentUserId,
  );
}
```
- 画面範囲内の投稿をフィルタリング
- 投稿の種類に応じた表示種別の決定
- 現在は座標調整なしでサーバー座標をそのまま使用

### 3. UIコンポーネントの実装

#### BubbleWidget (`lib/features/post/widgets/bubble_widget.dart`)
```dart
class BubbleWidget extends StatelessWidget {
  final Post post;
  final VoidCallback? onTap;
}

class BubblePainter extends CustomPainter {
  // カスタム吹き出し描画
}
```
- 吹き出し形状のカスタム描画
- ユーザー投稿（青）と土地の記憶（緑）の色分け
- テキスト省略とタップ処理対応

### 4. MapScreen への統合

#### 地図表示の更新
- 水彩画風の地図スタイル (`stamen_watercolor`) を適用
- 吹き出し表示のためのMarkerLayerを追加
- 地図回転時の表示安定化（`rotate: true`）

#### 状態管理の追加
```dart
final BubbleManager _bubbleManager = BubbleManager();
final SimplePostService _simplePostService = SimplePostService();
List<Post> _posts = [];
List<BubblePosition> _bubblePositions = [];
```

#### イベント処理
- 地図移動時の吹き出し位置更新
- 吹き出しタップ時の詳細表示ダイアログ
- 初期化時のデモ投稿追加

## 技術的な特徴

### 1. 画面範囲での効率的なフィルタリング
- `ViewBounds`を使用して表示領域内の投稿のみを処理
- パフォーマンスを考慮した実装

### 2. 柔軟な表示システム
- 投稿種別による色分け
- タップ時の詳細表示
- 地図回転に対応した描画

### 3. 開発ツールとの統合
- 仮想位置でのテスト対応
- デバッグログによる状態確認
