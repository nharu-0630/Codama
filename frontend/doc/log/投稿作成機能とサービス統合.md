## 概要

投稿システムの大幅な改善を実施しました。複数のサービスファイルを統合し、投稿作成UIを追加し、API/モック両対応の設計に変更しました。

### 1. 投稿サービスの統合

#### 削除されたファイル
- `lib/features/post/services/simple_post_service.dart` - シンプルな投稿管理サービスを削除

#### 新規作成されたファイル
- `lib/features/post/services/post_service.dart` - API/モック両対応の統合サービス

#### サービス統合の特徴
```dart
class PostService {
  static const bool _useApi = false; // TODO: 本番時はtrueに変更
```

## 技術的な改善

### サービス設計パターン
- **Strategy Pattern**: API/モック実装の切り替え
- **Facade Pattern**: 複雑なサービス操作を単一インターフェースで提供
- **Error Handling**: 例外の適切な伝播とUI層での処理

### 非同期処理の改善
```dart
// 投稿読み込み
Future<void> _loadPosts() async {
  if (_isLoadingPosts) return; // 重複実行防止
  
  setState(() { _isLoadingPosts = true; });
  
  try {
    final posts = await _postService.getAllPosts();
    setState(() {
      _posts = posts;
      _isLoadingPosts = false;
    });
    _updateBubblePositions();
  } catch (e) {
    setState(() { _isLoadingPosts = false; });
    LocationConfig.log(LocationConfig.mapScreenTag, '❌ 投稿読み込みエラー: $e');
  }
}
```

### UI/UX改善
- **ローディング状態**: 投稿作成中のボタン無効化＋スピナー表示
- **バリデーション**: リアルタイム文字数表示
- **フィードバック**: エラー時のみスナックバー表示（成功通知は削除）
