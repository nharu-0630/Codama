# 開発者ツール実装ログ

**実装日**: 2025-10-25  
**対象**: フェーズ2 開発者ツール実装  
**目的**: 仮想位置操作のための開発ツール実装

## 📋 実装概要

Kodamaアプリの開発効率向上のため、GPS代替となる仮想位置操作ツールを実装。開発者がエミュレータやテスト環境で位置情報をシミュレートできる機能を提供。

## 🎯 実装した機能

### 1. DevJoystick ウィジェット
**ファイル**: `lib/features/map/widgets/dev_tools/dev_joystick.dart`

- **機能**:
  - 円形ドラッグエリア（直径100dp）
  - 中央ノブ操作による座標変換
  - 操作終了時の自動センタリング
  - リアルタイム地図座標変換

- **技術仕様**:
  - 最大ドラッグ距離: 30dp
  - 移動感度: 0.0003倍率
  - 緯度・経度の正負方向調整（Y軸反転）
  - ドラッグ中の視覚フィードバック

- **UI仕様**:
  - 背景: 半透明黒（0x88000000）
  - ノブ: 白色、ドロップシャドウ付き
  - 操作中は青色にハイライト

### 2. DevLocationService クラス
**ファイル**: `lib/features/map/widgets/dev_tools/dev_location_service.dart`

- **機能**:
  - シングルトン仮想位置管理
  - DEV_TOOLS環境変数による制御
  - 本番環境での完全無効化
  - デバッグログ機能

- **制御ロジック**:
  ```dart
  static bool get isDevToolsEnabled {
    if (!kDebugMode) return false;
    final devToolsValue = dotenv.env['DEV_TOOLS']?.toLowerCase();
    return devToolsValue == 'true';
  }
  ```

- **API**:
  - `setVirtualLocation(LatLng)`: 仮想位置設定
  - `getVirtualLocation()`: 仮想位置取得
  - `clearVirtualLocation()`: 仮想位置クリア
  - `hasVirtualLocation`: 設定状態確認

### 3. LocationService 拡張
**ファイル**: `lib/features/location/services/location_service.dart`

- **追加機能**:
  - 開発モード判定機能
  - 仮想位置優先取得ロジック
  - GPS位置とのシームレス切り替え
  - 強化デバッグログ

- **実装ロジック**:
  ```dart
  // 開発ツールが有効で仮想位置が設定されている場合は仮想位置を優先
  if (DevLocationService.isDevToolsEnabled) {
    final virtualLocation = _devLocationService.getVirtualLocation();
    if (virtualLocation != null) {
      return virtualLocation;
    }
  }
  // 通常のGPS取得処理
  ```

### 4. LiveLocationController 拡張
**ファイル**: `lib/features/location/services/live_location_controller.dart`

- **追加機能**:
  - 仮想位置ストリーム対応
  - アプリライフサイクル管理
  - デュアルストリーム管理（GPS/仮想）

- **ストリーム管理**:
  - `_positionSubscription`: GPS位置ストリーム
  - `_virtualPositionSubscription`: 仮想位置ストリーム
  - バックグラウンド制御対応

### 5. MapScreen 統合
**ファイル**: `lib/features/map/presentation/map_screen.dart`

- **UI統合**:
  - 条件分岐表示（`kDebugMode && DEV_TOOLS=true`）
  - ジョイスティック左下配置
  - 開発モード状態表示（右下）
  - 現在地マーカーの視覚的差別化

- **動作制御**:
  - 現在地と地図中心の分離
  - ジョイスティック操作時の地図追従
  - コンパスボタン機能の改善

## 🎮 操作仕様

### 基本操作
1. **開発ツール有効化**: `.env`ファイルで`DEV_TOOLS=true`設定
2. **ジョイスティック操作**: 左下の円形コントローラーをドラッグ
3. **位置確認**: 右下の開発モード表示で座標確認
4. **現在地復帰**: コンパスボタンで現在位置に移動

### 地図操作の分離
- **通常の地図操作**: 自由なパン・ズーム（現在地更新に影響されない）
- **ジョイスティック操作時**: 地図中心が現在地に追従
- **現在地マーカー**: 実際の位置（または仮想位置）に固定表示

- **開発モード**: 🛠️ オレンジ色のマーカー
- **通常モード**: 📍 青色のマーカー

## 🔧 技術的詳細

### 環境制御
- **開発環境**: `kDebugMode && DEV_TOOLS=true`で有効
- **本番環境**: 完全無効化（パフォーマンス影響なし）
- **環境変数**: `.env`ファイルによる制御

### 座標変換アルゴリズム
```dart
// 正規化されたオフセット（-1.0 〜 1.0の範囲）
final normalizedX = offset.dx / _maxDragDistance;
final normalizedY = offset.dy / _maxDragDistance;

// 緯度・経度の変更量を計算
final deltaLng = normalizedX * _movementSensitivity;
final deltaLat = -normalizedY * _movementSensitivity; // Y軸反転
```

### ログ出力仕様
- **ジョイスティック操作**: 操作開始/終了、座標変更
- **仮想位置管理**: 設定/取得/クリア操作
- **地図制御**: 中心移動、現在地復帰
