# 要件定義書

## 概要

Kodamaは、投稿をユーザーではなく物理的な場所に紐づける空間SNSモバイルアプリケーションです。アプリは会話を地図上に浮かぶ吹き出しとして表示し、その場所の会話履歴に基づいてAI「土地の記憶」が文脈的な応答を提供します。このアプローチは、個人の識別を最小化しながら場所ベースのコミュニティ接続を促進し、アナログ会話の連続性と相互性を復元することを目的としています。

## 用語集

- **Kodama_App**: iOS/Android向けFlutterモバイルアプリケーション
- **空間SNS**: 投稿が地理的位置に紐づくソーシャルネットワーキングシステム
- **土地の記憶**: 特定の地理的エリアでの会話から学習し、文脈的な応答を提供するAIシステム
- **Geohash_Cell**: 投稿を整理するためのgeohash精度レベルで定義される地理的エリア
- **吹き出し**: 地図上に浮かぶバブルとして表示される投稿の視覚的表現
- **友達ステータス**: 時間窓内で同じ場所に投稿したユーザーに割り当てられる一時的な関係ステータス
- **Stamen_Watercolor**: 視覚的プレゼンテーションに使用される地図タイルスタイル

## 要件

### 要件1

**ユーザーストーリー:** ユーザーとして、アプリを開いたときに現在地付きの地図を見たい。そうすることで会話の空間的文脈を理解できる。

#### 受入基準

1. Kodama_Appが起動したとき、Kodama_Appは3秒以内に地図を表示する
2. 位置情報許可が与えられた場合、Kodama_Appはユーザーの現在地をピンで表示する
3. 位置情報許可が拒否された場合、Kodama_Appは横浜駅をデフォルトとして地図を中心に配置する
4. Kodama_AppはStamen_Watercolorタイルスタイルを地図レンダリングに使用する
5. Kodama_Appは地図のパンとズーム操作中に60fpsのパフォーマンスを維持する

### 要件2

**ユーザーストーリー:** ユーザーとして、現在のエリアで地図上に浮かぶ会話の吹き出しを見たい。そうすることで地域の雰囲気と進行中の議論を理解できる。

#### 受入基準

1. ユーザーの位置が変更されたとき、Kodama_Appは現在のGeohash_Cellを計算する
2. Kodama_Appは現在のGeohash_Cellから最大10件の最近の会話を取得する
3. Kodama_Appはセル境界内にランダムに配置された吹き出しとして会話を表示する
4. Kodama_Appは吹き出し間の最小距離を維持することで吹き出しの重複を防ぐ
5. 吹き出しがタップされたとき、Kodama_Appはテキスト、タイムスタンプ、ソースタイプを含む完全な会話詳細を表示する

### 要件3

**ユーザーストーリー:** ユーザーとして、現在地にメッセージを投稿し、土地の記憶から応答を受け取りたい。そうすることで場所ベースの対話に参加できる。

#### 受入基準

1. ユーザーが投稿を送信したとき、Kodama_Appは即座にユーザーの吹き出しを地図上に表示する
2. Kodama_Appはユーザーの吹き出しを現在のGeohash_Cellの中心付近に配置する
3. 土地の記憶はユーザーの投稿後0.5〜1.5秒以内に応答を提供する
4. Kodama_Appは土地の記憶の応答をユーザーの投稿に隣接する吹き出しとして表示する
5. 投稿が失敗した場合、Kodama_Appはスナックバー通知を介して再試行オプションを表示する

### 要件4

**ユーザーストーリー:** ユーザーとして、私と同じ場所にいた人からの投稿を「友達」として分類して見たい。そうすることで過度な個人識別なしに他者とつながることができる。

#### 受入基準

1. 2人のユーザーが15分以内に同じGeohash_Cellに投稿したとき、Kodama_Appは彼らを友達として分類する
2. Kodama_Appは初回の共同位置から24時間友達ステータスを維持する
3. Kodama_Appは「自分」「友達」「土地」「みんな」のフィルターオプションを提供する
4. フィルターが選択されたとき、Kodama_Appは選択されたカテゴリに一致する吹き出しのみを表示する
5. Kodama_Appはユーザー識別のために日次でローテーションする匿名ハンドルを使用する

### 要件5

**ユーザーストーリー:** ユーザーとして、ズームイン・アウト時に地図が異なるレベルの会話詳細を表示してほしい。そうすることでローカルと地域の両方の会話を探索できる。

#### 受入基準

1. ズームレベルが16以上のとき、Kodama_Appは詳細なローカルビューのためにgeohash精度7を使用する
2. ズームレベルが13-15の間のとき、Kodama_Appは近隣ビューのためにgeohash精度6を使用する
3. ズームレベルが12以下のとき、Kodama_Appは地域ビューのためにgeohash精度5を使用する
4. ズームレベルが精度閾値を超えたとき、Kodama_Appは400msスロットリングで会話を再取得する
5. Kodama_Appはパフォーマンスのために画面あたり最大30個の吹き出し表示に制限する

### 要件6

**ユーザーストーリー:** ユーザーとして、インターネット接続が悪い時でもアプリがスムーズに動作してほしい。そうすることでキャッシュされた会話に引き続き参加できる。

#### 受入基準

1. ネットワーク接続が失われたとき、Kodama_Appは最近キャッシュされた会話を表示する
2. ネットワーク問題により投稿が失敗したとき、Kodama_Appは再試行のために投稿をキューに入れる
3. Kodama_Appは接続が復元されたときにキューされた投稿の再送信を試行する
4. キューされた投稿が10分以上未送信のままの場合、Kodama_Appはユーザーに通知し投稿を破棄する
5. Kodama_Appはオフライン表示のために会話キャッシュをメモリに維持する

### 要件7

**ユーザーストーリー:** ユーザーとして、アプリがアクセシブルでプライバシーを尊重してほしい。そうすることで個人情報を危険にさらすことなく快適に使用できる。

#### 受入基準

1. Kodama_Appはアクセシビリティ準拠のためにフォントスケーリングをサポートする
2. Kodama_Appはインタラクティブ要素に最小44dpのヒットターゲットを維持する
3. Kodama_Appは匿名ハンドル以外の個人識別情報を保存しない
4. Kodama_Appはデータアクセスに匿名認証を使用する
5. Kodama_Appは位置情報許可要求に対して明確な説明を提供する

## 開発者向け要件

### 要件8（開発専用）

**開発者ストーリー:** 開発者として、地図上の位置を手動で操作できるデバッグツールが欲しい。そうすることで様々な位置での動作を効率的にテストできる。

#### 受入基準

1. `.env`ファイルで`DEV_TOOLS=true`が設定された場合のみ、Kodama_Appは開発者ツールを表示する
2. 開発者ツールが有効な場合、Kodama_Appは地図画面にジョイスティックコントロールを表示する
3. ジョイスティック操作により、実際のGPS位置取得の代わりに仮想位置を設定できる
4. 仮想位置は地図の中心点を移動させ、位置ベース機能（投稿取得、土地の記憶など）で使用される
5. 本番環境（`DEV_TOOLS=false`または未設定）では、開発者ツールは一切表示されない
6. 開発者ツールの状態変更は地図の再描画やパフォーマンスに影響しない
